1. <meta description> — não existe no site
O que é: o texto que aparece abaixo do título no Google. Sem ele, o Google inventa um texto aleatório.
Onde colocar: dentro do <head> do index.html
html<meta name="description" content="Mini mercado autônomo para condomínios em Brasília e DF. Instalação gratuita, operação 24h, sem custo para o condomínio. Solicite um projeto para o seu condomínio.">

2. Schema Markup (dados estruturados) — não existe
O que é: código invisível que diz ao Google "sou uma empresa local, atendo Brasília, meu telefone é X". Isso alimenta o painel de conhecimento e o Maps.
Onde colocar: antes do </body> no index.html
html<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "LocalBusiness",
  "name": "Just Go Market",
  "description": "Mini mercado autônomo premium para condomínios em Brasília e entorno. Instalação e operação gratuita para o condomínio.",
  "url": "https://justgomarket.com.br",
  "telephone": "+55-61-99991-8007",
  "email": "justgomarket@justgomarket.com.br",
  "address": {
    "@type": "PostalAddress",
    "addressLocality": "Brasília",
    "addressRegion": "DF",
    "addressCountry": "BR"
  },
  "areaServed": ["Brasília", "Distrito Federal", "Entorno do DF"],
  "openingHours": "Mo-Su 00:00-23:59",
  "priceRange": "$$",
  "image": "https://justgomarket.com.br/assets/images/mini-mercado-autonomo-condominio-brasilia.jpg"
}
</script>

3. Tags H1 e H2 com palavras-chave — fracas
O que tem hoje: o H1 é "O Mercadinho, Reinventado: Autônomo & Premium." — criativo, mas o Google não entende o que é nem onde fica.
O que mudar: altere o H1 para incluir localização e serviço:
html<h1>Mini Mercado Autônomo para Condomínios em Brasília e DF</h1>
```

E adicione subtítulo visual separado (pode ser um `<p>` em destaque):
```
"O Mercadinho, Reinventado: Autônomo & Premium."

"Mercado 24h para condomínio no DF — custo zero"

5. Google Business Profile — provavelmente incompleto
Como verificar e configurar:

Acesse business.google.com
Procure por "Just Go Market"
Se não existir, crie. Se existir, reivindique
Preencha: categoria = "Loja de conveniência", horário = 24h, telefone, fotos da loja real, descrição com "mini mercado autônomo condomínio Brasília"
Peça para condomínios já atendidos deixarem avaliações — cada estrela melhora o ranking local
